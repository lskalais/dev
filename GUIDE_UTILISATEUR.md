# Guide utilisateur — Africa Legacy Partners

Version du guide : 9 novembre 2026  
Public : visiteurs, acquéreurs/investisseurs, cédants, courtiers et administrateurs ALP.

Ce guide décrit les fonctions présentes dans la version actuelle de l’application, également appelée **Africa Legacy Market** sur certains écrans. Les boutons disponibles dépendent de votre rôle, de la validation de votre profil et de l’état du dossier.

> La création d’un compte ne donne pas automatiquement accès aux identités des entreprises ou aux documents sensibles. Une validation de profil, un accord de confidentialité et des autorisations documentaires distinctes peuvent être nécessaires.

## 1. Accéder à la plateforme

Pour l’installation locale, ouvrez :

**[http://localhost/confidentia/home.xhtml](https://tributary-rework-defensive.ngrok-free.dev/confidentia/home.xhtml)**

Cette adresse fonctionne sur la machine qui héberge l’application. Pour un accès depuis un autre poste, utilisez l’adresse communiquée par ALP ; `localhost` ne désigne pas le serveur distant.

Un navigateur récent avec JavaScript et les cookies de session activés est recommandé.

### Sans compte

Depuis l’accueil, vous pouvez :

- découvrir les services ALP ;
- consulter les aperçus anonymisés dans **Opportunités** ou **Acheter** ;
- découvrir le parcours de cession dans **Vendre** ;
- lire les articles publiés dans **Articles et actualités** ;
- consulter la **FAQ** et les informations légales ;
- utiliser **Contact / réclamation**, accessible en pied de page ;
- choisir **Créer un compte** ou **Connexion**.

Une liste vide signifie qu’aucun contenu n’est actuellement disponible dans cette rubrique. Elle ne constitue pas une confirmation de panne.

### Choisir le bon profil

| Profil | Usage principal |
|---|---|
| Acquéreur / investisseur | Rechercher une entreprise, enregistrer des favoris et demander une introduction. |
| Cédant / propriétaire | Présenter une entreprise à céder, déposer les justificatifs et suivre les échanges. |
| Courtier / conseil M&A | Prendre en charge les dossiers autorisés, vérifier les profils et accompagner les opérations. |
| Administrateur ALP — SUPER | Administrer les comptes, contenus, messages, partenaires et opérations selon ses autorisations. |

Le rôle SUPER n’est pas proposé dans le formulaire d’inscription public.

## 2. Créer un compte et se connecter

### Inscription

1. Cliquez sur **Créer un compte**.
2. Renseignez votre nom ou celui du représentant légal et votre adresse courriel.
3. Sélectionnez votre rôle.
4. Complétez les informations correspondant à votre profil.
5. Choisissez un mot de passe d’au moins **12 caractères**.
6. Consultez les informations relatives aux données personnelles et l’engagement de confidentialité.
7. Cliquez sur **Créer mon compte**.
8. Lisez le message de confirmation ou corrigez les champs signalés.

### Informations propres aux acquéreurs

**Personne physique :** nationalité, pays de résidence, téléphone et profession. Vous pouvez également préciser une capacité financière indicative, sa devise et les secteurs recherchés.

**Personne morale :** dénomination sociale, téléphone du représentant, forme juridique, pays d’immatriculation, numéro RCCM ou registre équivalent, identifiant fiscal, siège social et fonction du représentant légal.

Utilisez des renseignements exacts et cohérents avec vos justificatifs. La capacité financière indicative n’est ni une preuve de financement ni une promesse d’investissement.

### Connexion

1. Ouvrez **Connexion**.
2. Saisissez votre courriel et votre mot de passe.
3. Cliquez sur **Se connecter**.
4. Accédez au tableau de bord correspondant à votre rôle.

Si ALP vous a attribué un mot de passe temporaire, l’application impose de choisir et de confirmer un nouveau mot de passe avant de poursuivre.

Pour quitter votre espace, utilisez **Déconnexion**, particulièrement sur un ordinateur partagé.

## 3. Comprendre la confidentialité

| Situation | Accès attendu |
|---|---|
| Visiteur public | Aperçu non identifiant : secteur, domaines, zone géographique, ancienneté et effectif par tranche. Fourchette de CA seulement si le cédant l’autorise. |
| Compte inscrit sans accord signé par les deux parties | Fonctions de son rôle, mais pas de révélation automatique des informations sensibles de l’entreprise. |
| Acquéreur vérifié et accord signé par les deux parties | Informations complémentaires autorisées du dossier, notamment identité, localisation précise et données financières disponibles. |
| Document de data room | Accès soumis aux autorisations documentaires et à la période de validité, en plus des conditions du dossier. |

**Trois validations différentes sont à distinguer :**

1. la vérification du profil ou du compte ;
2. la signature de l’accord de confidentialité pour une opération ;
3. l’autorisation d’accès à chaque document.

Ne placez jamais un nom d’entreprise, une adresse précise ou un indice permettant de l’identifier dans un champ destiné à un aperçu anonymisé.

## 4. Parcours acquéreur / investisseur

### 4.1 Faire vérifier son profil KYC

Dans le tableau de bord, repérez **Vérification de votre profil**.

1. Sélectionnez le type de pièce.
2. Choisissez un fichier lisible.
3. Utilisez le bouton de téléversement.
4. Vérifiez que le document apparaît dans la liste.
5. Consultez régulièrement le statut et les éventuelles demandes de complément.

| Type de compte | Pièces à préparer |
|---|---|
| Personne physique | Pièce d’identité. Justificatif d’origine des fonds uniquement si ALP le demande. |
| Personne morale | Immatriculation, statuts, identité du représentant légal et pouvoirs de représentation. Informations sur les bénéficiaires effectifs et origine des fonds si demandées. |

Les coordonnées sont vérifiées **manuellement** par un courtier ou un administrateur. Cette version n’envoie pas de code de vérification OTP par courriel ou SMS.

| Statut affiché | Action à entreprendre |
|---|---|
| Documents en attente | Déposer les pièces nécessaires. |
| Vérification en cours | Attendre la revue et surveiller les notifications. |
| Complément demandé | Lire le motif, puis déposer les pièces demandées. |
| Profil vérifié | Poursuivre les démarches autorisées ; les accords de confidentialité restent propres à chaque dossier. |

### 4.2 Enregistrer ses critères

Dans **Définir vos critères** :

1. indiquez les secteurs et la région recherchés ;
2. choisissez la devise des critères ;
3. saisissez l’investissement minimum et maximum ;
4. cliquez sur **Enregistrer mes critères**.

Ces critères servent au classement des opportunités compatibles. Le pourcentage de correspondance est une aide à la recherche, pas une recommandation d’investissement.

### 4.3 Rechercher et conserver des opportunités

Dans **Entreprises à découvrir**, utilisez les filtres disponibles : secteur, domaine, pays, zone, budget, chiffre d’affaires, rentabilité, années de création, effectif et type de transaction.

- Cliquez sur **Appliquer** pour lancer la recherche.
- Utilisez **Réinitialiser** pour retirer les filtres.
- Cliquez sur **Ajouter aux favoris** pour conserver une annonce dans votre liste privée.
- Utilisez **Afficher mes favoris**, puis **Voir toutes les annonces**, pour changer de vue.
- Utilisez **Retirer des favoris** pour enlever une annonce de votre sélection.

**Attention :** les filtres financiers exacts ne s’appliquent qu’aux dossiers dont l’accord de confidentialité est signé par les deux parties. Commencez par les critères non financiers pour explorer les annonces anonymisées.

### 4.4 Demander une introduction

Sur l’annonce souhaitée, cliquez sur **Demander une introduction**. Suivez ensuite la demande dans **Demandes et dossiers**.

L’acceptation d’une introduction ne vaut ni validation d’acquisition ni accès immédiat à tous les documents.

## 5. Parcours cédant / propriétaire

### 5.1 Déposer les justificatifs du compte

Dans **Pièces justificatives du cédant**, déposez séparément les documents correspondant aux types proposés :

- RCCM ou document d’immatriculation ;
- document fiscal ;
- statuts ;
- identité du représentant ;
- pouvoir de céder ou mandat ;
- autre pièce utile demandée.

Pour chaque pièce : choisissez son type, sélectionnez le fichier, cliquez sur **Téléverser la pièce chiffrée**, puis vérifiez sa présence dans la liste.

Le suivi du compte affiche :

| Statut | Signification |
|---|---|
| Documents en attente | Le dossier documentaire doit être constitué ou complété. |
| En vérification | Un réviseur examine les pièces. |
| Rejeté / à compléter | Des corrections sont attendues ; consultez le motif affiché. |
| Documents validés | Les pièces ont été acceptées ; la validation finale du compte est une étape distincte. |
| Compte validé | La vérification du compte cédant est finalisée. |

### 5.2 Présenter une entreprise

Dans **Présenter votre entreprise** :

1. choisissez un grand secteur : **primaire**, **secondaire** ou **tertiaire** ;
2. sélectionnez un ou plusieurs domaines d’activité ;
3. renseignez l’activité principale, l’année de création et l’effectif ;
4. indiquez le pays et une zone géographique non identifiante ;
5. rédigez une description anonymisée ;
6. complétez, selon votre dossier, la clientèle, les avantages concurrentiels, la raison de la vente, les conditions de cession et l’accompagnement envisagé ;
7. choisissez le type de transaction et la devise ;
8. renseignez les données financières disponibles ;
9. saisissez le nom réel et l’adresse précise uniquement dans les champs marqués **privé** ;
10. décidez si vous autorisez l’affichage public d’une fourchette de chiffre d’affaires ;
11. cliquez sur **Publier le teaser anonymisé**.

Le courriel du courtier est facultatif. En l’absence de courtier actif correspondant, le teaser peut être publié sans attribution, puis pris en charge par un courtier.

### 5.3 Modifier le teaser

Dans votre portefeuille, cliquez sur **Modifier le teaser**, effectuez les changements puis sur **Enregistrer les modifications**.

- La modification est possible jusqu’à la prise en charge par un courtier.
- Après cette prise en charge, le cédant ne peut plus modifier le teaser depuis ce parcours.
- Lors d’une modification, laisser le nom réel ou l’adresse privée vide conserve sa valeur actuelle.
- Utilisez **Créer un nouveau teaser** pour repartir sur une autre annonce.

### 5.4 Suivre les demandes et la cession

Traitez les demandes dans **Demandes et dossiers**, puis consultez **Parcours des annonces** pour l’étape de cession et son historique.

Les étapes prévues vont de l’inscription du cédant à la vérification, la préparation, la publication, les manifestations d’intérêt, l’accord de confidentialité, la revue documentaire, la négociation, la conclusion, l’accompagnement post-cession et la clôture.

Le cédant consulte le suivi. Le courtier mandaté ou l’administration fait avancer les étapes autorisées. Une étape affichée ne remplace pas les actes juridiques ou les vérifications professionnelles.

## 6. Demandes, signatures et échanges

### Accepter ou refuser une demande

Le cédant ou le courtier habilité utilise **Accepter** ou **Refuser** dans le dossier concerné.

### Signer l’accord de confidentialité

Après acceptation :

1. ouvrez le dossier en attente de signature ;
2. lisez les conditions de l’accord affiché ;
3. saisissez votre nom complet ;
4. cliquez sur **Signer l’accord de confidentialité** ;
5. attendez la signature de l’autre partie.

L’acquéreur doit disposer d’un profil KYC validé pour signer. Les signatures acquéreur et cédant sont distinctes : une seule signature ne révèle pas l’identité de l’entreprise.

> La signature enregistrée est un consentement électronique nominatif horodaté. Elle n’est pas présentée comme une signature électronique qualifiée. Vérifiez avec vos conseils si des formalités supplémentaires sont nécessaires.

### Échanger des messages

Après signature bilatérale, les parties utilisent **Ouvrir la messagerie**, rédigent leur message puis cliquent sur **Envoyer**.

Vérifiez le numéro de dossier avant chaque envoi. Les conversations privées sont réservées aux participants autorisés ; l’accès administratif à une revue documentaire n’équivaut pas à un accès général aux conversations.

### Organiser un rendez-vous

Dans la messagerie du dossier :

1. sélectionnez une date et une heure futures dans **Proposer une date et heure (heure locale)** ;
2. cliquez sur **Proposer le rendez-vous** ;
3. l’autre partie utilise **Confirmer** ou **Refuser** ;
4. consultez la liste pour connaître la réponse et l’historique.

Si vous êtes dans des pays différents, confirmez explicitement le fuseau horaire dans vos échanges. Une proposition n’est pas une confirmation.

## 7. Utiliser la data room

La data room regroupe les documents sensibles d’un dossier. Les pièces KYC, les documents généraux d’une annonce et les documents partagés dans une opération ne doivent pas être confondus.

### Déposer un fichier

1. Ouvrez le dossier concerné.
2. Dans **Data room**, sélectionnez le fichier.
3. Cliquez sur **Ajouter un document à la data room**.
4. Vérifiez son apparition et son état d’autorisation.

Formats proposés : **PDF, DOC, DOCX, XLS, XLSX, PNG, JPG et JPEG**. La limite technique par fichier est de **20 Mio** (20 × 1 024 × 1 024 octets). Déposez un fichier à la fois et conservez les originaux dans votre propre espace sécurisé.

Le dépôt est soumis aux droits de votre compte. Il ne rend pas automatiquement le fichier accessible à l’acquéreur.

### Autoriser l’accès

1. Le cédant renseigne une **durée d’accès de 1 à 365 jours**.
2. Il clique sur **Autoriser le partage**.
3. Le courtier mandaté ou l’administrateur habilité utilise **Valider par ALP**.
4. L’acquéreur peut ouvrir le lien lorsque les conditions du dossier et du document sont remplies.

La période commence après la dernière approbation requise. La date de fin apparaît près du document. Si la fenêtre est expirée ou non ouverte, le téléchargement n’est pas disponible pour l’acquéreur ; demandez à ALP ou au cédant d’examiner l’accès.

### Consulter le journal

Le cédant et les réviseurs habilités disposent du **Journal de consultation**, qui indique le document, l’utilisateur et la date de consultation enregistrée.

L’expiration de l’accès dans l’application n’efface pas une copie déjà téléchargée. Respectez les obligations de confidentialité, de restitution ou de suppression applicables.

## 8. Parcours courtier / conseil

### Prendre en charge une annonce

1. Consultez les annonces accessibles dans votre portefeuille.
2. Examinez les informations et pièces autorisées.
3. Utilisez **Accepter le dossier** lorsqu’il est proposé.
4. Traitez ensuite les demandes et les autorisations relevant de votre mandat.

La prise en charge verrouille les modifications du teaser par le cédant. Les actions de publication ou de suspension ne concernent que les annonces sur lesquelles vous disposez des droits nécessaires.

### Vérifier les cédants

Ouvrez **Vérification des cédants** :

1. consultez les justificatifs ;
2. cliquez sur **Commencer la vérification** ;
3. saisissez un motif et utilisez **Demander un complément** si nécessaire ;
4. sinon, utilisez **Valider les pièces** ;
5. finalisez séparément avec **Valider le compte cédant**.

### Vérifier les acquéreurs

Ouvrez **KYC acquéreurs** :

1. examinez le profil et les pièces ;
2. commencez la vérification ;
3. confirmez les vérifications manuelles du courriel et du téléphone ;
4. signalez, si nécessaire, les exigences relatives à l’origine des fonds ou aux bénéficiaires effectifs ;
5. demandez un complément motivé ou utilisez **Valider le profil KYC**.

Ne cochez une vérification qu’après avoir réellement effectué le contrôle correspondant.

### Retraiter les données financières

Sur un dossier pris en charge, la rubrique **Retraitement financier · EBITDA × multiple** permet de saisir le CA retraité, l’EBE/EBITDA retraité et un multiple de **0 à 30**, puis d’utiliser **Enregistrer les indicateurs**.

La valorisation est indicative et ne garantit pas un prix de vente. Une modification ultérieure des données du dossier invalide la validation antérieure.

## 9. Parcours administrateur ALP

Ces fonctions sont réservées au rôle **SUPER**, sauf celles également ouvertes aux réviseurs habilités.

### Comptes et indicateurs

Dans **Administration**, consultez les indicateurs : comptes, KYC et vérifications à finaliser, annonces actives ou suspendues, opérations en cours et nouveaux messages à traiter.

Pour créer un utilisateur :

1. renseignez le courriel, le nom, l’organisation et le rôle ;
2. attribuez un mot de passe temporaire ;
3. cliquez sur **Créer le compte** ;
4. transmettez les accès par un canal approprié, sans les publier dans une annonce ou un article.

Dans **Comptes existants**, l’action **Attribuer** permet de remplacer le mot de passe par un mot de passe temporaire. L’utilisateur devra le changer au prochain accès. La liste présente le statut KYC ; la revue des pièces s’effectue dans l’écran dédié.

### Annonces et suivi

Depuis le tableau de bord, utilisez **Suspendre l’annonce** ou **Publier l’annonce** selon l’état et vos droits. Consultez le parcours de cession et utilisez **Passer à l’étape suivante** uniquement après les vérifications utiles.

### Articles et actualités

Dans **Contenus et messages** :

1. cliquez sur **Nouvel article** ;
2. renseignez le titre, le thème, le résumé public et le contenu en texte brut ;
3. cliquez sur **Enregistrer le brouillon** ;
4. relisez le contenu, puis utilisez **Publier** ;
5. utilisez **Modifier** ou **Dépublier** si nécessaire.

Thèmes proposés : cession/transmission, reprise de PME, entrepreneuriat, économie et finance. Ne publiez aucune information confidentielle d’un dossier.

### Contacts et réclamations

Dans la même page, consultez les demandes reçues. Renseignez une note interne et faites évoluer le statut : **Nouveau**, **En cours**, **Résolu**, puis cliquez sur **Enregistrer le suivi**.

Cet écran n’envoie pas de réponse par courriel : utilisez les coordonnées fournies pour répondre hors plateforme.

### Partenaires et experts

Dans **Partenaires**, utilisez **Nouvelle fiche**, renseignez l’expertise, les coordonnées et la présentation, puis **Enregistrer**.

Les fiches peuvent être **modifiées**, **suspendues** ou **réactivées**. La suspension évite une suppression et retire la fiche de la consultation normale.

## 10. Notifications, partenaires et assistance

### Notifications

Consultez **Notifications récentes** dans le tableau de bord. Utilisez **Marquer comme lue** pour suivre les alertes déjà traitées.

Les courriels de notification dépendent de la configuration SMTP du serveur. L’absence de courriel ne signifie pas qu’aucune action n’est attendue : consultez l’application. Les SMS ne sont pas un canal à considérer comme disponible dans cette version.

### Annuaire des partenaires

Le bouton **Partenaires** donne accès à l’annuaire lorsque votre profil et vos droits le permettent. Si un message indique qu’une validation est nécessaire, faites finaliser votre profil auprès d’ALP.

L’annuaire couvre notamment experts-comptables, avocats, notaires, conseillers fiscaux, évaluateurs, banques et consultants.

### Contacter ALP

1. Ouvrez **Contact / réclamation** depuis le pied de page.
2. Choisissez **Demande de contact** ou **Réclamation**.
3. Renseignez votre nom, votre courriel, l’objet et le message ; le téléphone est facultatif.
4. Cliquez sur **Envoyer à ALP**.
5. Vérifiez le message affiché.

Le formulaire conserve la demande pour traitement par ALP. Il n’envoie pas automatiquement de courriel. Ne transmettez jamais votre mot de passe et évitez d’y joindre ou d’y recopier des informations sensibles non nécessaires.

## 11. Préférences et limites actuelles

### Langue

En pied de page, choisissez **Français** ou **English**, puis cliquez sur **Appliquer / Apply**. Le choix est conservé dans la session ; une déconnexion, une expiration ou un redémarrage du serveur peut nécessiter de le sélectionner à nouveau.

**La traduction est partielle :** les écrans d’inscription et de connexion, leurs libellés de thème et les éléments partagés associés ont été localisés. D’autres pages, libellés métier et contenus restent en français. Le sélecteur ne traduit pas automatiquement les annonces, articles ou messages saisis par les utilisateurs.

Par précaution, changez de langue avant de remplir un formulaire : la reconstruction de la page peut faire perdre des saisies non enregistrées.

### Apparence

Utilisez **Mode sombre / Mode clair**. Sur les écrans localisés, les boutons deviennent **Dark mode / Light mode**. Cette préférence est conservée dans le navigateur, pas nécessairement sur vos autres appareils.

### Pays et devises

Choisissez le pays et la devise correspondant à l’entreprise ou à votre capacité d’investissement. Lisez toujours le code de devise associé aux montants, par exemple XOF, EUR ou USD.

**Aucune conversion automatique n’est effectuée.** Un budget dans une devise ne doit pas être comparé directement à un prix dans une autre. Pour les filtres financiers, sélectionnez la devise voulue ; un montant identique dans deux devises n’a pas la même valeur.

### Informations légales et portée du service

Les pages légales sont accessibles en pied de page. Certains textes et coordonnées restent provisoires ou à compléter avant ouverture au public. Ce guide ne remplace ni les conditions applicables, ni un mandat, ni un conseil juridique, fiscal ou financier.

La plateforme ne garantit ni la conclusion d’une cession, ni son financement, ni une valorisation.

## 12. Résoudre un problème courant

| Problème | Vérifications et actions |
|---|---|
| Un champ ou un bouton signale une erreur | Lisez le message, corrigez les champs concernés, puis soumettez une seule fois à nouveau. |
| La session a expiré ou la vue ne peut pas être restaurée | Ouvrez à nouveau l’accueil ou la connexion depuis leur adresse, puis reconnectez-vous. Vérifiez si la précédente action a été enregistrée avant de la répéter. |
| Une page affiche HTTP 500 | Notez l’heure, l’adresse de la page et l’action réalisée. Essayez une page fraîche. Si l’erreur persiste, signalez-la à ALP ; ne la considérez pas comme une confirmation de réussite. |
| La page ne s’ouvre pas | Vérifiez l’adresse et la connexion. Sur un autre poste, remplacez `localhost` par l’adresse serveur communiquée par ALP. |
| L’identité de l’entreprise est encore masquée | Vérifiez la validation KYC et les signatures des deux parties dans ce dossier. |
| Un document est visible sans lien de téléchargement | Vérifiez l’autorisation du cédant, la validation ALP et la date d’expiration. Contactez le responsable du dossier si nécessaire. |
| Un fichier est refusé | Vérifiez le format proposé, la taille maximale de 20 Mio, le type de pièce choisi et la lisibilité du fichier. Ne changez pas simplement son extension. |
| Le teaser n’est plus modifiable | Vérifiez s’il a été pris en charge par un courtier ; demandez-lui la correction. |
| Aucun résultat de recherche | Retirez les filtres avec **Réinitialiser**. Vérifiez la devise et les restrictions des critères financiers avant NDA. |
| Aucun courriel reçu | Consultez les notifications internes. L’envoi par courriel dépend de la configuration du serveur. |
| Aucun code KYC reçu | Aucun OTP n’est envoyé dans cette version ; la vérification des coordonnées est manuelle. |
| Mot de passe oublié | Contactez ALP pour l’attribution d’un mot de passe temporaire ; aucun parcours public de réinitialisation autonome n’est décrit ici. |
| Une rubrique reste en français | La couverture bilingue n’est pas encore complète. |
| L’affichage ou un libellé paraît ancien | Enregistrez les données en cours, puis actualisez la page avec Ctrl+F5 sous Windows. Si le problème persiste, précisez le navigateur et sa version à ALP. |
| Un bouton d’administration est absent | Vérifiez le rôle connecté. Ne créez pas un autre compte pour contourner les droits ; contactez l’administrateur. |

Pour un signalement, indiquez votre rôle, le numéro du dossier si disponible, la page, l’heure et le texte du message. Masquez les informations confidentielles dans les captures d’écran. Ne transmettez jamais de mot de passe ni de cookie de session.
